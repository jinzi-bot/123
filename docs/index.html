安装步骤
  1. Android：下载 APK → 点击安装 → 允许未知来源 → 打开即用。
  2. Windows：双击 EXE（安装版按提示下一步）→ 首次启动可确认服务器地址 → 打开面板。
  3. iOS：Windows 电脑装 Apple Devices + Sideloadly → 数据线连 iPhone 并「信任此电脑」→ Sideloadly 拖入 IPA、填 Apple ID、Start → 手机上「设置 → 通用 → VPN与设备管理 → 信任」→ iOS 16+ 再到「隐私与安全性 → 开发者模式」打开并重启。
改服务器地址

三端默认连 http://150.138.73.130。要换地址：Android 右上角 ⋮ → 服务器设置；Windows 菜单 应用 → 服务器设置；iOS 右上角 ⚙。地址可填 IP、域名，带不带 http:// 都可以。

iOS 为什么要自己签名？能直接装吗？

苹果系统不允许运行未签名代码，所以任何 IPA 都必须带证书才能安装：App Store（$99/年）、企业证书（第三方购买）、或用自己的 Apple ID 免费签名（本页走这条，7 天有效，到期重签一次即可，数据不丢）。

如果你的 iPhone 系统在 TrollStore 支持范围内（≤ iOS 16.6.1 或 17.0），也可以用 TrollStore 直接安装未签名 IPA，长期有效。
